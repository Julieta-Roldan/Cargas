Configuración de Base de Datos (Supabase)

Conectá tu proyecto de Supabase para guardar en la nube en tiempo real.

Código SQL para crear la tabla en Supabase (1 clic)

En Supabase andá a SQL Editor → New Query, pegá esto y dale a Run: 

create table if not exists public.movimientos (
  id bigint generated by default as identity primary key,
  tipo text not null default 'DEPOSITO',
  usuario text not null,
  monto numeric not null default 0,
  billetera text default '',
  hora text not null,
  fecha_dia text not null,
  turno text default '',
  verificado boolean default false,
  created_at timestamptz default now()
);

alter table public.movimientos enable row level security;

create policy "Acceso publico total movimientos"
  on public.movimientos for all
  using (true)
  with check (true);
